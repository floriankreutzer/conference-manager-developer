# Developer Documentation

Human-readable public guides around approved Conference Manager partner API releases will live here.

Planned sections:

- `getting-started/` — onboarding and first successful synthetic request;
- `authentication/` — credential lifecycle, scopes, revocation and rotation;
- `catering/v1/` — Caterer API concepts and lifecycle guides;
- `security/` — integration security expectations and safe webhook handling;
- `versioning/` — compatibility, deprecation and migration policy.

Endpoint and schema authority remains the release-published OpenAPI artifact sourced from `conference-manager-api`. Guides must not redefine it.
