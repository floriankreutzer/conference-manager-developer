# Contributing

This repository is intentionally narrow: publish only information required by an external integrator to implement, authenticate, validate, troubleshoot, migrate, or safely operate an approved Conference Manager public API.

Before contributing, read `AGENTS.md`.

Changes must use a pull request. Do not publish internal architecture, roadmap material, provider research, customer/Tenant data, credentials, production payloads, or unreleased API behavior.

Published OpenAPI artifacts must originate from an approved backend contract and include the required provenance metadata. Examples must be synthetic.

A change is ready only after the repository's public-documentation safety checks pass.
