# Security

Report suspected vulnerabilities privately using **Report a vulnerability** on the
[Conference Manager Website reporting entry point](https://github.com/floriankreutzer/conference-manager-website/security/advisories)
while signed in to GitHub. This canonical route covers all Conference Manager components.

Read the [product-wide disclosure and response policy](https://github.com/floriankreutzer/conference-manager-website/blob/main/SECURITY.md)
for report scope and handling expectations. No paid bounty or guaranteed response/remediation SLA is established.

Do not report sensitive findings in public issues or pull requests. Do not include credentials,
customer data, production payloads or unnecessary personal data. Use minimized, redacted evidence
and test only accounts and environments you are authorized to access.
